How a CSRF attempt is stopped

This page intentionally does not send a forged request or initiate a transfer. It is a safe explanation of the browser trust boundary for this local lab.

01
Victim is signed in

A browser may attach applicable cookies automatically to requests it makes to a site.

02
Cross-site request is attempted

In a vulnerable design, an endpoint that changes state on GET can confuse ambient authentication with user intent.

03
SecureBank denies the GET

GET /transfer returns HTTP 405. A legitimate POST also needs the session-bound CSRF token.

Observed protection: no transfer is performed by visiting this page. Use the dashboard form to make a legitimate transfer.
